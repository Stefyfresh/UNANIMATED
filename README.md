# UNANIMATED

A custom animation system mod for the hit rhythm game UNBEATABLE!

This mod makes charting for Arcade Mode much more visually interesting than the base game.

> [!IMPORTANT]
> UNANIMATED is currently in alpha and is a work in progress!
> If you are looking to try it, you may download the pre-release version, but it is not the final version!
> Things may change, the format may be modified a bit, and there may be bugs, but if you would still like to try it, by all means feel free!

## Features

This list of features is currently implemented in the mod!

- Full control over the camera
  - Change position (all 3 axes)
  - Change rotation (all 3 axes)
  - Change ease time and ease mode
  - Change FOV
- Background video support in any stage
- Swappable stages mid-chart
- Swappable characters mid-chart
- Change the time of day and the weather during gameplay
- Hide or show any UI elements during gameplay
- And more!

## Configuration

UNANIMATED has a few configuration options that alter how it functions:

### Enable UNANIMATED

This is a global toggle for UNANIMATED. If UNANIMATED is not enabled, it will not perform any custom actions on custom charts with UNANIMATED events in the chart, and the chart will play as if you do not have the mod installed at all.

### Enable Scene Switching

Enables UNANIMATED's scene switching feature. If disabled, it will only use the default scene for that particular chart or your currently selected scene in the base game settings.
Scene switching has a memory, performance, and chart load time impact, so this setting is included in case that is not desired.

### Enable Forced Default Stage

If enabled, any charts that include a command to set the default stage will have the custom default stage force enabled whether or not you have selected default stage in your base game settings.
This is useful for keeping the charter's intent intact, but if you do not want this to be enabled you can disable it.

## Usage

If you would like to try out UNANIMATED, the easiest way is to download the UNBEATABLE Standalone Editor from ErikGXDev and enable UNANIMATED support, then try out all the features by playing around with them!

The format is not finalized yet, when it is I will link a guide for the full documentation of the UNANIMATED event format.
